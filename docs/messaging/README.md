# Messaging

Source material for site copy from comms/marketing and the founders. Pages are written from what's here, not invented.

**This repository is public.** Put only material that's fine to publish here: approved messaging, key messages, voice and tone guidance. Keep drafts, personal notes, and anything not cleared for release outside the repo.

Suggested layout:

- `key-messages.md`: positioning, taglines, the one-paragraph description
- `voice-and-tone.md`: how we sound, words to use and avoid
- `founders.md`: the founders' story for Our Story
- `audiences.md`: what each audience (candidates, enlisted members, donors, schools and units) needs to hear

Standing rule from the brand palette: describe the colors as representing all who serve, and never tie messaging or color to a single branch. See `../BRAND.md`.
